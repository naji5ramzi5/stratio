═══ BUG #1: Random PnL Generation ═══
File: run_full_system.py, lines 242-244

Exactly the problem you asked about. The exit PnL was generated
randomly instead of from actual price differences. This is 100%
invalid as validation.

═══════════════════════════════════════════════════════════════════
═══ BUG #2: Same Data Every Day ═══
File: run_full_system.py, run_day() and _check_regime()

Every "day" calls:
    klines = fetch_klines(symbol, "1h", 200)  # LIVE data!
Then pretends it's a historical day.

This means all 100 "days" were processed with the SAME live snapshot
of Binance data, then random NP noise was injected for exits.

The +22% result was completely fabricated by this combination.
